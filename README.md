An immersive, interactive 3D portfolio website featuring floating particles, orbiting tech icons, and stunning visual effects. Built with React Three Fiber for a truly memorable first impression.

🌐 **[Live Demo](https://kartheek-portfolio.vercel.app)** | 📧 **papasanikarthik@gmail.com**

---

## ✨ Features

### 🎨 Immersive 3D Experience
- **21+ Three.js Components** across 6 sections
- Anti-gravity floating particles throughout
- Orbiting tech stack spheres with hover effects
- Fibonacci sphere skill node network
- Achievement badge orbital system
- Smooth 60fps animations

### 🎯 Portfolio Sections
| Section | 3D Effects |
|---------|------------|
| **Hero** | Particle galaxy, orbiting tech icons, floating geometry |
| **About** | Floating profile plane, gentle particles |
| **Projects** | Tech constellation network, floating particles |
| **Skills** | Node-based network, category-colored particles |
| **Achievements** | Orbiting badges, celebration confetti |
| **Contact** | Social icon spheres, contact particles |

### 📱 Responsive & Performant
- Optimized WebGL rendering with `dpr` scaling
- Smooth scrolling between sections
- Glass-morphism UI components
- Dark theme with soft lavender/sky blue accents

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/Vkchowdary05/3d-portfolio.git

# Navigate to project
cd 3d-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the portfolio.

### Build for Production

```bash
npm run build
npm run preview
```
